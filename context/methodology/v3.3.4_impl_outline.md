# v3.3.4 구현 outline — per-topic PE variance calibration

목표: v3.3.2 의 global hard PE threshold 를 likelihood calibration 으로 흡수하는 신규 segmenter 를 만든다. 이 문서는 구현 계획이며, 현재 단계에서는 Python 파일을 생성하지 않는다.

  - topic별 scalar PE mean / variance EMA 상태 유지
  - likelihood 를 $-\mathrm{PE}^2/(2\sigma_k^2)$ 로 계산
- `tests/test_v334_variance.py`
  - EMA update, cold-start fallback, likelihood ranking, read-only query 테스트

수정:

- `src/hi_em/orchestrator.py`
  - `version == "v3.3.4"` 분기 추가
  - `HiEMSegmenterV334` import 추가
  - variance HP 전달

  - `--method choices` 에 `hi-em-full-v3.3.4` 추가
  - method 생성 분기에서 `version="v3.3.4"` 전달
  - argparse 에 `pe_var_decay`, `pe_var_min_samples`, `pe_var_sigma0_sq`, `pe_var_min_sq`, `pe_var_max_sq`, `var_likelihood_weight`, `hard_pe_fallback` 추가

## 기본 HP

v3.3.2 best HP 위에서 calibration HP 만 추가한다.

| HP | default | 근거 |
|---|---:|---|
| `cos_threshold` | 0.9 | fresh baseline PE $\mathrm{PE}_0=0.1$ 로 재해석 |
| `alpha` | 100.0 | v3.3.1 HP sweep best |
| `beta` | 0.25 | v3.3.1 HP sweep best |
| `lmda` | 10.0 | v3.3.2 sweep 에서 낮추면 악화 |
| `rnn_train_steps` | 3 | v3.3.2 best |
| `pe_var_decay` | 0.95 | EMA effective window 약 20 |
| `pe_var_min_samples` | 5 | 작은 topic variance guard |
| `pe_var_sigma0_sq` | 0.04 | cold-start PE std 0.2 |
| `pe_var_min_sq` | 1e-4 | zero variance 방지 |
| `pe_var_max_sq` | 0.25 | 넓은 topic 이 모든 PE 를 흡수하는 것 방지 |
| `var_likelihood_weight` | 1.0 | calibrated likelihood scale |
| `hard_pe_fallback` | false | v3.3.4 핵심 비교는 hard threshold 제거 |

`pe_threshold` 는 compatibility 목적으로 남길 수 있지만 `hard_pe_fallback=false` 일 때 사용하지 않는다.

## 구현 단계

1. state 초기화
   - arrays: `pe_mean`, `pe_var`, `pe_var_count`.
   - 새 topic 생성 시 `pe_mean=0.0`, `pe_var=pe_var_sigma0_sq`, `count=0`.
2. likelihood 계산
   - $\mathrm{PE}_{n,k}=1-\cos(s_n,\hat{s}_{n,k})$.
   - usable variance: `pe_var_sigma0_sq` if `pe_var_count[k] < pe_var_min_samples`, else clipped `pe_var[k]`.
   - `log_lik = - pe * pe / (2 * sigma2)`.
   - final score: `log(prior[k]) + var_likelihood_weight * log_lik`.
3. fresh score
   - `pe0 = 1 - cos_threshold`.
   - `fresh_lik = - pe0 * pe0 / (2 * pe_var_sigma0_sq)`.
   - `score_new = log(alpha) + var_likelihood_weight * fresh_lik`.
4. update
   - chosen existing topic 의 observed PE 로 EMA update.
   - 새 topic 은 첫 sample update 를 건너뛰거나 PE=pe0 로 seed. 기본안은 `pe_var_count=0` 유지 후 다음 repeat 부터 update.
5. read-only `predict_topic()`
   - score 계산은 동일.
   - PE variance arrays, counts, topics, prev_k 변경 없음.
6. logging
   - experiment config 에 variance HP 저장.
   - 가능하면 debug snapshot 에 topic별 `pe_mean`, `pe_var`, `pe_var_count` 를 포함.

## 테스트 계획

`tests/test_v334_variance.py`

1. `test_pe_variance_ema_updates_assigned_topic_only`
   - 선택된 topic 의 EMA 상태만 변경.
2. `test_cold_start_uses_sigma0_until_min_samples`
   - `pe_var_count < pe_var_min_samples` 에서는 fallback 사용.
3. `test_small_variance_penalizes_same_pe_more`
   - 같은 PE 에 대해 작은 $\sigma_k^2$ topic 의 score 가 낮음.
4. `test_fresh_score_uses_cos_threshold_as_pe0`
   - `cos_threshold=0.9` 이면 `pe0=0.1` 로 fresh likelihood 계산.
5. `test_hard_pe_fallback_disabled_by_default`
   - MAP / likelihood ratio 만으로 boundary 결정.
6. `test_predict_topic_read_only_for_variance_state`
   - variance arrays, counts, prev_k 변경 없음.
7. `test_variance_floor_and_cap_applied`
   - pathological PE sequence 에서 floor / cap 확인.
