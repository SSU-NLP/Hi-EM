# v3.3.4-2 — σ² shrinkage + robust scale

CLI method: `hi-em-full-v3.3.4-2`. orchestrator `version="v3.3.4-2"`. Segmenter class: `HiEMSegmenterV334_2` (구현 2026-05-10).

## 한 줄

v3.3.4 의 per-topic cosine PE 분산 EMA 위에 **Bayesian shrinkage** 를 얹어 작은 topic 의 σ_k² 를 global prior σ_0² 로 안정화한다. 옵션으로 robust (MAD 기반) EMA 스케일도 제공한다.

## 동기

v3.3.4 first sweep (2026-05-09 LoCoMo 1986Q) 에서 retrieval R-mh@k +20.7% 향상이 acc 평균 변화로는 옮지 못함. 분석 결과 Welford EMA σ_k² 가 작은 topic / 적은 sample 에서 over- 또는 under-estimate 되어 likelihood ratio MAP 결정을 흔드는 것으로 추정. 또한 fresh score `S_{K+1} = log α - PE_0²/(2σ_0²)` 가 `α` 와 `σ_0²` 둘 다에 비대칭 의존 → sweep 공간 큼.

v3.3.4-2 는 SEM 의 Gaussian PE 정신을 유지하되 Bayesian noise prior 를 온라인 근사로 추가한다.

## Shrinkage 공식

각 topic $k$ 의 effective variance:

$$\sigma_{k,\mathrm{eff}}^2 = \eta_k \cdot \sigma_{k,\mathrm{raw}}^2 + (1-\eta_k) \cdot \sigma_0^2,\quad \eta_k = \frac{n_k}{n_k + c}$$

- `c = pe_var_shrink_c` (default `8`) 는 prior strength.
- `n_k = pe_var_count[k]` 는 누적 PE 샘플 수.
- $\sigma_{k,\mathrm{raw}}^2$: default 는 v3.3.4 와 동일한 Welford EMA squared deviation; `pe_var_robust=True` 옵션 시 $1.4826 \cdot d_k$ (MAD EMA) 로 바꿈.
- 모든 결과 값은 `[pe_var_min_sq, pe_var_max_sq]` clip.

Cold-start (`n_k < pe_var_min_samples`) 에서는 v3.3.4 와 동일하게 σ_0² fallback.

## Robust EMA (옵션, default OFF)

absolute deviation EMA:

$$d_k \leftarrow (1-\rho) d_k + \rho |\mathrm{PE} - m_k^{\mathrm{new}}|,\quad \sigma_{k,\mathrm{robust}}^2 = (1.4826 \, d_k)^2$$

cosine PE 분포가 heavy-tail 일 때 outlier turn 한두 개가 squared deviation EMA 를 부풀리는 것을 막는다. 추가 EMA 1회만 — latency 영향 무시 가능.

## Cross-cutting HP (sweep 시 함께 고려)

본 segmenter 가 의존하는 다른 cross-cutting HP. `infrastructure.md` 참조.

- **Segmenter base** (v3.3.4 와 동일): `alpha`, `lmda`, `tau`, `cos_threshold`, `beta`, `pe_threshold`, `rnn_train_steps`, `rnn_hidden_dim`, `rnn_lr`, `rnn_max_context`, `rnn_min_history`. cosine PE 환경에서 segmentation 행동에 직접 영향.
- **STM cap (HiEM common, retrieval 분포에 직접 영향)**:
  - `stm_max_topics` (default 10) — STM 안 동시 유지 topic 수 cap
  - `stm_max_turns` (default 200) — STM 전체 turn 수 cap (prefill 길이 결정)
  - `promotion_threshold` (default 0.5) — 새 topic 이 STM 진입할 importance 임계
  - `importance_alpha`, `lambda_r`, `lambda_freq`, `min_floor` — importance 함수 파라미터

## SEM 계승 정당화

- shrinkage prior 는 **새 메커니즘**. SEM 원논문 / SEM2 에 직접 없음. 도입 정당화 (CLAUDE.md SEM 계승 § 3-step):
  1. **SEM 에 왜 없는가**: SEM2 는 controlled VAE 영상 자극으로 event-별 noise scale 학습 부담이 작았다 (v3.3.4.md "SEM 계승 정당화" 와 동일 분석). 작은-event-수 데이터에서 σ_k² 학습이 안정적이지 못한 문제 자체를 SEM2 가 회피했음.
  2. **충돌 없음**: shrinkage 는 likelihood term 의 noise scale parameterization 변경. sCRP / Bayes / local MAP / scene dynamics 와 직교. SEM 의 Bayesian 구조는 prior · likelihood 곱 형태이고, σ_k² 자체에 prior 를 두는 것은 hierarchical Bayesian 자연 확장.
  3. **decision-log entry**: `context/06-decision-log.md` 2026-05-10 v3.3.4-2 첫 LoCoMo sanity (acc +0.008) 항목.

- `pe_var_robust` 도 SEM 에 없음. cosine PE 가 Gaussian 가정과 어긋날 가능성에 대한 보수 옵션. default OFF 라 v3.3.4-2 main 평가는 squared EMA 로 진행.

## 알려진 한계

1. **shrinkage 강도 `c=8` 임의 선택** — 적정 prior strength 는 데이터 특성 (PE 분포 폭 + topic 분포) 에 의존. sweep 필요.
2. **R@k 약손실 (-0.008)**: v3.3.4 의 high R@k (R-mh +20.7%) 가 일부 깎였다. shrinkage 가 작은 topic 의 PE 변화를 덜 민감하게 만들어 evidence retrieval 폭이 좁아짐. acc 향상이 이 trade-off 를 보상함.
3. **rag-observation (0.267) 대비 여전히 회귀**: hi-em 변형 끼리의 비교에서만 의미 있음. RAG 우위는 별도 설계로 풀어야 함 (turn-level rerank 미구현 또는 다른 구조).
4. **first-turn random RNN init seed 의존성**: T1var 가 v3.3.4 (18.8) 대비 약간 늘었음 (27.5±9). robust EMA 옵션이 도움될지 sweep 으로 확인.

## 고려 중인 변형

1. **adaptive `c` per-topic**: prior strength 를 일정하지 않게 — large `n_k` 면 빠르게 shrinkage 풀어주기.
2. **fresh σ adaptive**: `σ_fresh² = median(σ_eff²)` 로 fresh slot baseline 을 active topic 분산 따라가게.
3. **turn-level rerank** (v3.3.4.md 권장 항목 + codex iter1 recommendation 미구현): STM atomicity 를 깨고 query cosine top-K turn 으로 prefill 재구성. shrinkage 와 직교.
4. **v3.3.3-2 와 결합**: 같은 segmenter 가 prototype f0 + posterior odds + σ shrinkage 를 모두 갖도록. 다만 두 변경 효과가 독립인지 ablation 필요.
